## About Me

* Software Engineer at [TikTok](https://www.bytedance.com/en), working on large-scale backend and distributed systems.
* Creator of [Emberling](https://github.com/leungll/Emberling), an AI-native runtime platform for long-horizon Agents, now evolving into Agent Infra for cloud Agent workloads.
* M.S. in Software Engineering from [Carnegie Mellon University](https://www.cmu.edu/), where I worked with Prof. [Leonardo Sousa](https://ssousaleo.github.io/) in the Distributed Systems Research Group.
* Interested in durable execution, Agent Harness design, and Evals for long-running, stateful Agents.
* Sharing what I learn through [technical writing](https://leungll.site).
